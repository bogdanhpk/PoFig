# Как выпустить обновление

1. Обновите номер версии в `Cargo.toml`, приложениях для Mac и Windows, ссылки в README и описание новой версии в `docs/releases/`.
2. Соберите приложения с помощью скриптов в папке `scripts/`.
3. Отправьте изменения в GitHub и дождитесь успешных проверок.
4. Создайте тег `vНомер.Версии` и черновик выпуска на странице **Releases**.
5. Загрузите архивы для Mac, Windows и Windows на ARM, исходники и файл `SHA256SUMS.txt`.
6. Проверьте файлы и опубликуйте выпуск. PoFig увидит его при следующей проверке.
7. Проверьте ссылки из README и обновление из предыдущей версии PoFig.

В архив для Mac добавьте файл **OPEN-MAC-FIRST.txt**. В описании выпуска укажите изменения, которые увидит пользователь, и ссылку на инструкцию первого открытия.

Пока версия тестируется, отмечайте выпуск как **Pre-release**. Сборки, личные настройки и файлы с паролями в исходники не добавляйте.

Для обновлений из приложения используйте архивы из скриптов сборки: они содержат помощник и список файлов. Имена архивов: `PoFig-macOS.zip`, `PoFig-win-x64.zip`, `PoFig-win-arm64.zip`. Публикуйте выпуск после загрузки всех трёх архивов.
