# PoFig v0.1.3

После выхода из Figma окно PoFig автоматически возвращается из трея на передний план. На macOS значок снова появляется в Dock, на Windows — на панели задач.

- При запуске Figma PoFig по-прежнему скрывается в строку меню или трей.
- При полном завершении Figma прокси останавливается, окно PoFig появляется, выбранный профиль сохраняется, кнопка «Запустить Figma» снова доступна.
- Обновление статуса само по себе не открывает вручную скрытое окно PoFig.

На Mac используйте **⌘Q** для выхода из Figma. Закрытие окна красной кнопкой может оставить приложение Figma запущенным.

Нативная проверка macOS проверяет скрытие после запуска, автоматический возврат после события завершения Figma, видимость в Dock и возможность повторного запуска с тем же профилем. Интерфейс Windows ещё требует ручной проверки на Windows.

Mac-пакет подписан локально, без Developer ID и нотариализации Apple. Инструкция **OPEN-MAC-FIRST.txt** находится в ZIP рядом с `PoFig.app`.
