# PoFig v0.1.5

Кнопки под списком прокси на macOS и Windows получили короткие подписи без многоточий: **Добавить прокси**, **Изменить**, **Удалить**. Подсказка и инструкция используют те же названия.

Mac-пакет подписан локально, без Developer ID и нотариализации Apple. Инструкция **OPEN-MAC-FIRST.txt** находится в ZIP рядом с `PoFig.app`.
