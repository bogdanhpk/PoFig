PoFig теперь обновляется из приложения.

- Автоматически проверяет новые выпуски в GitHub.
- Показывает кнопку «Обновить» и скачивает подходящую сборку.
- Устанавливает обновление после закрытия Figma и перезапускается.
- Сохраняет прокси и пароли. Если установка прервалась, восстанавливает предыдущую версию.

Версию 0.2.0 нужно установить из архива один раз. Следующие обновления можно устанавливать из PoFig.
