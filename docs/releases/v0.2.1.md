Обновления PoFig из приложения.

- PoFig проверяет новые выпуски на GitHub и предлагает установить подходящую сборку.
- Кнопка «Обновить» появляется только при наличии новой версии.
- Ручная проверка доступна в меню PoFig и меню его значка.
- Исправлен автоматический перезапуск после установки на Mac.
- Прокси и пароли сохраняются при обновлении.

Установите 0.2.1 из архива один раз. Следующие версии можно обновлять из PoFig. Перед установкой обновления полностью закройте Figma.
