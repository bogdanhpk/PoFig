# PoFig v0.1.4

В окне «О PoFig» указан автор: **Разработчик и создатель — Богдан Хтоминский**.

- macOS: пункт **PoFig → О PoFig**, стандартное системное окно с версией и автором.
- Windows: пункт **О PoFig** в контекстном меню значка PoFig в трее. Диалог показывает версию и автора.

Mac-пакет подписан локально, без Developer ID и нотариализации Apple. Инструкция **OPEN-MAC-FIRST.txt** находится в ZIP рядом с `PoFig.app`.
