# PoFig v0.1.2

Основное окно macOS и Windows стало компактнее: начальная рабочая область — 600 × 440. При необходимости окно можно увеличить.

- Уменьшены отступы и высота заголовка; сохранены системные размеры кнопок.
- На macOS адрес прокси отображается в строке списка без дублирования под ним.
- На Windows путь к Figma занимает оставшееся место рядом с кнопкой выбора; длинный путь сокращается.
- Подсказки переносятся по ширине окна. Список прокси прокручивается.

Интерфейс macOS проверен в компактном размере. Сборка Windows проверяется в GitHub Actions; её интерфейс ещё требует ручной проверки на Windows.

Mac-пакет подписан локально, без Developer ID и нотариализации Apple. Инструкция **OPEN-MAC-FIRST.txt** находится в ZIP рядом с `PoFig.app`.
