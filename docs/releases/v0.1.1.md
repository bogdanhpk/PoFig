# PoFig v0.1.1

Исправлено управление сохранёнными прокси на macOS и Windows.

- Редактирование по двойному клику и кнопки «Изменить прокси…» и «Удалить прокси…» доступны во время работы Figma.
- Под списком показана подсказка. Изменения сохраняются для следующего запуска Figma, а текущее соединение продолжает работать с прежними настройками.
- Перед удалением прокси и сохранённого пароля запрашивается подтверждение.
- После изменения или удаления сохраняется правильный выбор в списке. Двойной клик по пустому месту списка не открывает редактор.

## Проверка

Нативный тест macOS проверяет изменение профиля во время активного сеанса, сохранение без создания дубликата, отмену правок, отмену и подтверждение удаления, сохранение выбора и состояние пустого списка. Интерфейс Windows ещё требует ручной проверки на Windows.

## Первое открытие на Mac

Mac-пакет подписан локально, без Developer ID и нотариализации Apple. Инструкция **OPEN-MAC-FIRST.txt** находится в ZIP рядом с `PoFig.app`.
