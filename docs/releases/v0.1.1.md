# PoFig 0.1.1

Исправлено управление прокси.

- Прокси можно изменять и удалять при открытой Figma.
- Перед удалением появляется подтверждение.
- После изменения или удаления сохраняется правильный выбор в списке.

Новые настройки применяются при следующем запуске Figma через PoFig.

[Как открыть PoFig на Mac](https://github.com/bogdanhpk/PoFig/blob/main/macos/OPEN-FIRST.txt).
