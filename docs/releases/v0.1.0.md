# PoFig 0.1.0

Первая версия PoFig для Mac и Windows.

- Сохранение прокси и запуск официальной Figma.
- Работа с HTTP, HTTPS и SOCKS5.
- Хранение паролей в системе.
- Значок PoFig в строке меню или трее.
- Стеклянная иконка на тёмно-красном фоне.

[Как открыть PoFig на Mac](https://github.com/bogdanhpk/PoFig/blob/main/macos/OPEN-FIRST.txt).
