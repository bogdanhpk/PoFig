# PoFig v0.1.0

Первая предварительная версия нативных настроек прокси для официального клиента Figma.

- HTTP, HTTPS и SOCKS5, профили прокси и системное хранение паролей.
- macOS: AppKit, автоматическое скрытие в верхнюю строку меню после запуска Figma, возврат настроек через значок.
- Windows: Windows Forms, скрытие в трей и возврат окна из меню или повторным запуском приложения.
- Стеклянная иконка на приглушённом красном фоне.
- Универсальный пакет macOS для Intel и Apple Silicon; пакеты Windows x64 и ARM64.

## Первое открытие на Mac

Этот пакет подписан локально, без Developer ID и нотариализации Apple. В ZIP рядом с `PoFig.app` есть файл **OPEN-MAC-FIRST.txt** на русском языке. Он описывает индивидуальное разрешение запуска через системные настройки для неподтверждённого разработчика.

## Проверка и ограничения

На macOS проверены запуск Figma 126.11.8 через тестовый прокси, восстановление настройки после завершения Figma, скрытие и возврат окна с сохранением работающего прокси. Сетевые тесты и тесты IPC пройдены. Пакеты Windows собраны; их интерфейс на Windows ещё не проверен.

Поддерживается HTTP Basic и SOCKS5 с логином и паролем; NTLM, Kerberos и PAC пока не реализованы. Внешний браузер для входа и отдельный обновлятор Figma используют собственные настройки сети.
